# Crown Content — WBO Video Team

Booking site for the WBO Video Team (TMW 33). One self-contained page: index.html (fonts, images and the cover film are embedded).

- `index.html` is the site.
- `impressum.html` and `datenschutz.html` are DRAFTS: fill in the yellow placeholders before going public.
- `videos/` holds Arafan's portfolio films (the gallery loads them from /videos/*.mp4).

Netlify deploys every push to `main` automatically; there is no build step (see netlify.toml).
